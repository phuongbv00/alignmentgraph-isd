Internal convention: OOP labs use the starter repository pattern — every lab ships a Git repo with failing tests and TODO markers so learners code against executable specifications.

Rubric anchor set for design exercises (0-4 per criterion): correctness (tests pass), encapsulation (no leaked mutable state), naming (domain vocabulary), and justification (trade-off note in the PR description).

Common fresher misconception: inheritance as code reuse. Labs must include one exercise where composition is the correct answer and inheritance visibly breaks.

\section*{Data Availability}
ISD-Agent-Bench, including all six baseline agents and the evaluation
pipeline, is publicly available~\cite{isdagentbench}. The frozen run manifest
(code and prompt hashes, model checkpoints, seeds, dataset splits, decoding and
serving configuration, output and trajectory caps, judge prompts, and metric
versions), the four ablation-arm configurations, the stored trajectories and the
MAS source code will be released with the camera-ready version of this paper.
The manifest is what makes the reported statistics reproducible without
regenerating any model output.
